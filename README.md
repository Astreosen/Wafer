# Wafer
Realistic Circuit/Chip Builder

INITIAL RELEASE: 

Started in September, Uploaded to GitHub on November 23rd. 
Currently the app lets you build Simple circuits with power, cables, and resistors.

Transistors are a work in progress, and currently do nothing.

HOW TO USE: 
Download Java File and run the Main in an IDE such as Eclipse. After that it is mouse clicks to place stuff. 
Press enter to finish placing cables. 

KNOWN ISSUES:
